## About the Project

This is an Excel dashboard I created to analyze the performance of sales executives across different cities.

The dashboard helps to quickly compare sales executives, total sales, target achievement, and how far each executive is from their target.

## Dashboard Features

- City-wise filtering
- Total sales by sales executive
- Sales executive performance comparison
- Target achievement percentage
- Away from target percentage
- Sales distribution among executives
- Interactive dashboard using Excel controls and PivotTables

## Key Analysis

The dashboard mainly focuses on:

- Comparing total sales of different sales executives
- Checking the percentage of target achieved
- Identifying executives who are closer to or further from their target
- Comparing performance across different cities

## Tools Used

- Microsoft Excel
- PivotTables
- PivotCharts
- Excel formulas
- Conditional formatting
- Slicers / interactive filters
- Dashboard design

## Project Structure

- `RAW DATA` – Original sales data
- `DASHBOARD` – Final interactive dashboard

## What I Learned

Through this project, I learned how to convert raw sales data into an interactive dashboard.

I got practical experience with PivotTables, charts, filters, formulas, and presenting data in a simple way so that sales performance can be understood quickly.
